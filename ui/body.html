歌詞

  • 1行が1フレーズ。空行は少し間を空けます
  • 夜明けの色を/覚えてる … / でカットの切れ目を指定
  • *透明* … 強調（大きく・インパクト寄りの演出）
  • 行末の ! … フラッシュと揺れを入れる
  • 歌詞|ruby or note … 注釈レイアウトの小さな文字
  • [01:23.45]歌詞 … LRC のタイムスタンプをそのまま使用
  • [間奏 8] … 8秒の間奏（歌詞は出さず、背景と装飾だけ）。秒数を省くと4秒、タップ同期やマーカーで長さを合わせられます
  • # で始まる行 … コメント（無視）

    画面に見えているプレビューは自動でループします。

    グリーンバック／ブラックバックにすると、白い文字と演出だけを単色の背景の上に描きます（背景の模様・紙の質感・粒子・周辺減光は入りません）。プレビューにもそのまま反映されます。グリーンバックは動画編集ソフトのクロマキーで、ブラックバックは「スクリーン」合成や輝度キーで抜いて、別の映像の上に重ねられます。

    初期化

    次のものをすべて消して、最初の状態に戻します。元に戻すことはできません。

    • 歌詞・曲名・アーティスト
    • 読み込んだ曲（このブラウザに残していた分も）
    • タイミング・行ごとの指定・書き出す範囲
    • スタイル・演出・配色・書体などの設定
    • 案の履歴（◀ ▶）と、歌詞・タイミングの「元に戻す」の履歴

    表示モード（かんたん／詳細）・プレビューの音量・画面の言語はそのままです。保存したプロジェクトファイル（.json）も消えません。
